# AI-Powered-PostManager-Backend
Build Web application that allows a business user to create and manage Google Business Profile (GBP) posts with the help of AI.


## Overview

Backend API for managing Google Business Profile posts.

## Features

1.User registration and login
2.JWT authentication
3.Mock business locations
4.Create, update and delete posts
5.Draft and publish posts
6.AI content generation using OpenRouter

## Tech Stack

1.Node.js
2.Express.js
3.MongoDB
4.Mongoose
5.JWT
6.OpenRouter API
